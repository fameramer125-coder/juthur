# المكتبةُ الصوتيّةُ — عقدُ التسليم

كلُّ ما يلزمُ لإدخالِ تسجيلٍ إلى الموقع: ملفٌّ صوتيٌّ في `/audio/`، ومدخلٌ واحدٌ في `/audio/manifest.json`.
لا يُعدَّلُ أيُّ ملفٍّ آخر. الصفحاتُ تلتقطُ التسجيلَ وحدَها.

## المدخل

```json
{
  "id": "stories/07",
  "title": "الْمِفْتَاحُ الَّذِي لَا يَفْتَح",
  "corpus": "stories",
  "src": "/audio/stories-07.m4a",
  "duration": "4:12",
  "reciter": "قارئٌ مُجاز",
  "recorded": "2026-08-20",
  "notes": ""
}
```

| الحقل | ملزم | الشرح |
| :-- | :-: | :-- |
| `id` | نعم | مفتاحُ الربط. للقصص `stories/NN` بصفرٍ بادئ (`stories/01` … `stories/60`). للأسفار `asfar/NN`. لحروفِ الأسفار `harf/NN`. للملاحم `epics/N`. للميثاق `mushafaha`. |
| `title` | نعم | العنوانُ كما يظهر في المكتبة الصوتيّة |
| `corpus` | نعم | `stories` · `asfar` · `harf` · `epics` · `doctrine` |
| `src` | نعم | المسارُ المطلق للملفّ داخل `/audio/` |
| `duration` | لا | `م:ثث` — يُعرَض للقارئ |
| `reciter` | لا | بلا اسمٍ شخصيٍّ لزميلٍ أو طفل |
| `recorded` | لا | `YYYY-MM-DD` |
| `notes` | لا | ملاحظةٌ قصيرة |

## الصيغة

- **m4a (AAC)** أو **mp3**، أُحاديُّ القناة، ٤٤٫١ kHz، ٩٦–١٢٨ kbps. الصوتُ البشريُّ لا يحتاجُ أكثر.
- تسميةُ الملفّ من `id` بإبدالِ `/` بـ `-`: `stories/07` ← `stories-07.m4a`.
- بلا موسيقى تحت الصوت، وبلا مؤثّرات. المشافهةُ صوتُ إنسانٍ لا إنتاجٌ إذاعيّ.

## الأحكامُ الملزِمة (بنية الموقع IA v2 §4)

- **التنزيلُ متاحٌ دائمًا** لا الاستماعُ وحدَه — معلّمٌ في صفٍّ بلا شبكةٍ هو الحالةُ العاديّةُ لا الاستثناء.
- **مشغّلٌ فقط.** لا موجةٌ متحرّكة، ولا تشغيلٌ تلقائيّ، ولا منصّةٌ مضمَّنةٌ تُتبِعُ المقطعَ بمقطع.
- **لا فيديو في أيِّ موضعٍ من الموقع.**
