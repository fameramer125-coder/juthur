# Juthur Design System

هذا نظام التصميم الرسمي لمشروع جُذور (Amer, 2024) — الرموز والمكوّنات التي تحكم كل مُخرَج بصري: الكتب، الموقع، هَب الأوراق البحثية، وأي مواد تعليمية لاحقًا (محاضرات، أوراق شرح للطلبة).

## الرموز الثابتة (Tokens)
- **الألوان:** `src/tokens/colors.js` — INK `#1B3A2F` · GOLD `#9A7B23` · Paper `#FBF9F4`. لا لون ثالث؛ أي درجة جديدة تُشتقّ من INK أو GOLD فقط.
- **الطباعة:** `src/tokens/typography.js` — العربية دائمًا Amiri وRTL بسطر ≥ ٢.٠ مع التشكيل؛ اللاتينية EB Garamond.

## المكوّنات (Components)
- `Button` — زرّ أساسي (INK) وثانوي (حدّ GOLD)، مع حالة hover تتحوّل لـGOLD.
- `ArabicHeading` — عنوان عربي RTL بخط Amiri ولون INK.
- `Card` — بطاقة محتوى بخلفية Paper وحدّ GOLD خفيف.

## التوسّع المستقبلي
هذه النواة مصمَّمة لتُبنى عليها لاحقًا مكوّنات لكل سطح بصري لديك: صفحات كتب مطبوعة، لوحة هَب الأوراق البحثية، شرائح محاضرات، أوراق عمل الطلبة — بدل تكرار الألوان والخطوط يدويًّا في كل ملف HTML/Word منفصل.
